### <a name="_3bfxc9a45514"></a>**Функциональные требования**

| **№** | **Действующие лица или системы** | **Use Case**                                       | **Описание**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| :---: | :------------------------------- | :------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
|   1   | Клиент                           | Работа с кредитными предложениями на сайте         | 1. Новый клиент может просматривать доступные кредитные предложения и подавать заявки на сайте банка.<br>2. Клиент заходит на сайт банка, видит список доступных кредитов с актуальными ставками.<br>3. Полная информация об условиях кредита хранится в Кредитном конвейере.<br>4. Клиент может подать заявку, оставив ФИО и номер телефона.<br>5. При заполнении паспортных данных система запрашивает данные из системы скоринга.<br>6. Система выдает решение об одобрении или неодобрении кредита.<br>7. Клиенту отправляется СМС о необходимости прийти в отделение для идентификации. |
|   2   | Клиент                           | Работа с кредитными предложениями в интернет-банке | 1. Зарегистрированный клиент может просматривать кредитные предложения и подавать заявки через интернет-банк.<br>2. Клиент входит в интернет-банк, видит список доступных кредитов с актуальными условиями.<br>3. Клиенту могут выводиться персонализированные предложения (предодобрение).<br>4. Клиент может подать заявку на кредит.<br>5. При наличии предодобренного предложения система проводит упрощенную процедуру скоринга.<br>6. Клиент подтверждает операцию СМС-кодом.<br>7. Заявка отправляется в банк.                                                                        |
|   3   | Менеджер                         | Обработка заявки на кредит                         | 1. Менеджер обрабатывает заявку на кредит <br>2. Если клиент уже получил предварительное одобрение на сайте, менеджер продолжает работу с той же заявкой.<br>4. Для новых клиентов создается новая заявка через АБС.<br>5. Заявки по предодобренным предложениям обрабатываются в течение рабочего дня.                                                                                                                                                                                                                                |
|   4   | Система                          | Информирование клиента об изменении статуса заявки | 1. Система отслеживает изменение статуса заявки на кредит.<br>2. При изменении статуса система формирует СМС-уведомление и отправляет клиенту.<br>                                                                                                                                                                                                                                                                                                                                                 |

### <a name="_u8xz25hbrgql"></a>**Нефункциональные требования**

| **№** | **Требование**                                                                                                                  |
| :---: | :------------------------------------------------------------------------------------------------------------------------------ |
|  U1   | Максимально удобный интерфейс для клиента                                                                                       |
|  U51  | Научиться обрабатывать заявки в тот же день (сейчас ограничивает выгрузка из АБС раз в сутки)                                   |
|  R1   | Доступ ко всем сервисам 24/7 и 99.9% времени                                                                                    |
|  R2   | Сервисы интерет банка доступны при сбое ЦОД                                                                                     |
|  R3   | Система скоринга должна быть высоко доступна в рабочие часы                                                                     |
|  R4   | Данные клиентов необходимо защищать с помощью механизма шифрования трафика.                                                     |
|  P1   | Отклик по всем операциям должен быть порядка миллисекунд                                                                        |
|  S2   | Кредитный конвейер и система кредитного скоринга могут масштабироваться горизонтально                                           |
|  +R3  | Использовать языки программирования в которых есть эксепртность в банке (PHP, JAVA Spring, SQL, Python Flask, JS react, C# net) |
